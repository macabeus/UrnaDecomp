# docs/

What each document covers and how far to trust it. **Current** means it describes the repository as it is and is
kept up to date with it; **generated** means a script writes it; **results** means the numbers are those of the run
it names and are not refreshed.

| document | what it covers | status |
| --- | --- | --- |
| [getting-started.md](getting-started.md) | from a fresh clone to a verified splat build: host tools, `tools/setup/bootstrap.sh`, the pinned image, the first link | current |
| [how-to-decompile.md](how-to-decompile.md) | one function from its readout to a match: the work list and the function's stub, lift, `try-tu.sh`, landing a unit, census, symbols, `splat-match` (which removes the stub), the splat build (the one statement of that order), and how to read a library row | current |
| [improving-the-lifter.md](improving-the-lifter.md) | what a better lifter means here, how to pick a gap, the tests and the benchmark, and the known gaps | current |
| [status.md](status.md) | **the meter**: matched functions and bytes per component and per origin (TSE code, upstream libraries), what `unknown` holds, the scan's verdicts, the census tiers as diagnostics | generated by `make -C src status` from `splat/scan.tsv`; CI checks it |
| [glossary.md](glossary.md) | every term of the project: TSE, uenux2, ecourna, component, census, match, twin, band, … | current |
| [agents.md](agents.md) | rules for several agents working on one checkout, and the house rules every contributor follows | current |
| [reference/toolchain.md](reference/toolchain.md) | how the target was built: emsdk 6.0.0, the link line, the flags of every component, what the post-link optimiser does | current |
| [reference/app-flags.md](reference/app-flags.md) | the flags of TSE's application code (uenux2, ecourna), where each is set, the `std::source_location` records and the path mapping | current |
| [reference/splat.md](reference/splat.md) | the splat build: split, symbols, substitution, the drift rule, how to match a function, how to read the meter | current |
| [reference/include-asm.md](reference/include-asm.md) | why there is no `INCLUDE_ASM`: what the wasm toolchain does to an included body, and why the splat build plus generated comment stubs is the design | current (a decision record; its numbers are those of the research note it cites) |
| [reference/link-order.md](reference/link-order.md) | the function-order law and the solver that inverts it into link ordinals | the law is current; the tables are results of the solves it describes, on frozen links. The solve cannot be rerun from a clone: some of its inputs come from one-off commands that are not in the repository (§6), so `ledger/ordinals.tsv` and `ledger/tu-clusters.tsv` are frozen results |
| [reference/tu-slices.md](reference/tu-slices.md) | the target's function order cut into probable translation units | generated by `tools/linkorder/tu_slices.py` from the frozen solve |
| [reference/appmap.md](reference/appmap.md) | what the module contains: components and sizes, the source tree, subsystems, class hierarchies | results of the extraction by `tools/extract/`; its summaries come from `tools/extract/appmap_data.py` |
| [reference/facts/](reference/facts/README.md) | the measured facts the code and docs cite (`§T`, `§L`, `§F`, `§B`, `§A`, `§S`, `§X` ids), each with its evidence | current |

Other documentation lives next to what it describes: `README.md` (start here),
`target/README.md`, `build/README.md` (the toolchain pin), `src/README.md`, `src/units/README.md`,
`src/asn1/README.md`, `tools/README.md`, `ledger/README.md`, `third_party/MANIFEST.md`, and the toolkit's
`asmlift-wasm/README.md`, `asmlift-wasm/benchmark/README.md` and `asmlift-wasm/playground/README.md`. The Claude Code
command `.claude/commands/decompile-functions.md` runs a decompilation round on top of these documents.
